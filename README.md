# 💸 Splitzy

A modern expense splitter web application that helps users split expenses easily and calculate individual shares.

## 🚀 Features

- Add expenses
- Split expenses among multiple people
- Automatic calculation
- Responsive UI
- Clean and modern design

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## 🌐 Live Demo

https://eclectic-dusk-565acc.netlify.app/

## ⚙️ Installation

1. Clone the repository
2. Open index.html
3. Start using Splitzy
